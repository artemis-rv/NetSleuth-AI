# NetSleuth-AI

## Project Purpose
NetSleuth-AI is an advanced network and security analysis project designed to process, analyze, correlate, and report on network packet intelligence.

## Engine Ownership
- **M1**: Input + Packet Intelligence
- **M2**: Analysis Engine
- **M3**: Correlation + Investigation Engine
- **M4**: Evidence + Reporting Engine
